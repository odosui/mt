# Features

## Quizzes

- [x] F1: User can view the quizzes for a given note by clicking on the "Quizzes" button.

It's going to open the right panel with a list of quizzes. When there are not quizzes, the placeholder is shown saying "No quizzes yet.".

- [x] F2: User can create a quiz for a given note by clicking on the "+" button within the quizzes panel.

After it clicks it a form pops up, with the fields: title, text (area with max 65536 characters), number of questions (max 100, default 10), and a select box to choose a model, and extra instructions (an optional field). After user clicks "generate quiz" button, the quiz is generated by calling anthropic APIs. While it's generating, a loading spinner is shown. After it finishes, user is back to the list view with the new quiz added.
